PNG、PDF 和 SVG 源包保留原课程成品。SVG 含内嵌图像，解压后可直接在浏览器打开；字体取决于设备安装情况。HTML 是单图外链预览版，可下载后直接打开；七幅允许收录的外部图例已嵌入，成锦一项以官方链接呈现。此处理仅针对图例预览页面，不对原课堂 PPT 的再分发权限作判断。

八章图表实例用于说明时间轴、地图、流程、纹样图版、色卡、矩阵、人物关系和用户旅程的组织方式，外部实例的数据与人物均不属于傣锦项目。Cotton Australia 流程图的课堂节选未随公开版再分发，页面提供官方教材第 10 页链接。

课程展板采用项目的生成式工艺插图及网站图像档案。工艺拆分是信息图设计，不表示所有地区均有固定八步；器具插图不是文物复原。色卡取自数字图像，不是织物实测颜色。原网站档案图像不因进入本目录而获得新的再利用许可。
